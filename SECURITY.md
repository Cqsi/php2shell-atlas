# Security policy

If you find a security issue in PHP2Shell Atlas, please use [GitHub's private vulnerability reporting](https://github.com/Cqsi/php2shell-atlas/security/advisories/new). Include the affected URL or file, steps to reproduce, and the potential impact. Please do not put exploit details or credentials in a public issue.

This repository tracks an external PHP incident. Reports about the PHP vulnerabilities themselves should go to the PHP project's security process; this private reporting channel is for issues in PHP2Shell Atlas.
